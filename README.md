# anbernic-rgxx-ports

_Precompiled ports for Anbernic XX-series (Allwinner H700) stock OS_

## Downloads
- [Doom](https://github.com/epassaro/anbernic-stock-ports/releases/download/latest/Doom.zip) (Shareware)
- [Heretic](https://github.com/epassaro/anbernic-stock-ports/releases/download/latest/Heretic.zip) (Shareware)

## Installation
Download and uncompress the Zip files in the `ROMS/PORTS` folder. 
> **NOTICE:** these games are distributed with free or shareware data, then if you want to play the full game you must own an original copy and place the assets in the appropriate folder.   

## Why Stock OS?
Most Anbernic users prefer installing a new firmware that supports PortMaster, but that's not my case. I like the Stock OS, and also I think it is more fun to compile these games on my own.

For more information on how these games are built please refer to:
- [https://github.com/epassaro/anbernic-stock-ports](https://github.com/epassaro/anbernic-stock-ports)
- [https://github.com/epassaro/anbernic-stock-builder](https://github.com/epassaro/anbernic-stock-ports)
